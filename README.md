
# Husna Qadeer — Personal Portfolio

Welcome to my personal portfolio! This project showcases my introduction, technical skills, and journey as an aspiring web developer.

## About the Project

This portfolio is designed to introduce me, highlight the technologies I am learning, and provide a way to contact me. It features a clean, modern design with a dark green background and lime-green accents.

## Features

- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Navigation Bar:** Provides easy navigation between sections.
- **Hero Section:** Introduces me and my interest in web development.
- **About Section:** Shares information about me and my learning goals.
- **Skills Section:** Displays my current technical skills.
- **Contact Links:** Allows visitors to contact me through email.
- **GitHub Link:** Connects visitors to my GitHub profile.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/husnaqadeer/husna-portfolio.git
```

### 2. Open the Project Folder

```bash
cd husna-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio in your browser.
